# BLE Communication Flow

The T-003 design is integrated into the project report:

- [BLE Access and Security Concept](report/chapters/03-ideas-and-concepts.md#ble-access-and-security-concept): actors, connection and identification, check-in/check-out, initial errors, security, and design decisions.
- [Offline Operation and Synchronization](report/chapters/03-ideas-and-concepts.md#offline-operation-and-synchronization): ticket validity, offline limits, and receipt synchronization.
- [Detailed Security Documentation](report/chapters/08-appendices.md#detailed-security-documentation): recovery and synchronization proposals.

The diagrams are stored as PNG images and editable Mermaid sources in [report/assets](report/assets). The flow is a design proposal; the report records the open team decisions.
